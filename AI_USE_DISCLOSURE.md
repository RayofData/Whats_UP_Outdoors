## Project-Specific Disclosure

AI was used to help formulate the project plan, generate ideas, recommend learning resources, suggest tools, and assist with code generation. Tool and implementation choices were made by the author.

AI-generated code was reviewed line by line, typed manually, tested, and modified as needed. The author verified functionality, consulted documentation when necessary, and also incorporated review feedback from a mentor through pull requests.
